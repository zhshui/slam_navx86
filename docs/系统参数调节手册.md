## 1. 系统架构概览

```
┌────────────────────────── Gateway (Express) ──────────┐
│  Web 前端 ←→ HTTP/WS ←→ 导航控制 / 地图管理 / 遥测     │
└────────────────────┬─────────────────────────────────┘
                     │ /move_base_simple/goal (rosbridge)
                     ▼
┌────────────── move_base ─────────────────────────────┐
│  ┌─ Global Planner (GlobalPlanner)                    │
│  │   └─ global_costmap (static + stvl + inflation)   │
│  └─ Local Planner (TebLocalPlannerROS)                │
│      └─ local_costmap (static + stvl + inflation)    │
└────────────────────┬─────────────────────────────────┘
                     │ /cmd_vel
                     ▼
┌─────────── 定位 (hdl_localization) ──────────────────┐
│  - NDT 点云匹配                                       │
│  - UKF 滤波                                           │
│  - 全局重定位 (hdl_global_localization)               │
└──────────────────────────────────────────────────────┘
```

**配置文件位置**：`lite_cog/nav/src/navigation/config/`

|------|----------|
| `teb_local_planner_params.yaml` | `/move_base/TebLocalPlannerROS` |

## 2. TEB 局部规划器参数

**文件**：[teb_local_planner_params.yaml](lite_cog/nav/src/navigation/config/teb_local_planner_params.yaml)

### 2.1 机器人运动约束

| 参数 | 当前值 | 说明 | 调节建议 |
|------|--------|------|----------|
| `max_vel_x` | 1.0 m/s | 最大前向线速度 | 室内降低到 0.5-0.8；室外开阔可到 1.5 |
| `max_vel_x_backwards` | 0.2 m/s | 最大后退速度 | 四足通常不需要后退，保持较小值 |
| `max_vel_y` | 0.1 m/s | 最大横向速度 | 四足非全向底盘，保持接近 0 |
| `max_vel_trans` | 1.0 m/s | 最大合速度 | 应 ≥ max_vel_x |
| `max_vel_theta` | 1.5 rad/s | 最大旋转角速度 | 降低可让转弯更平稳 |
| `acc_lim_x` | 1.0 m/s² | 线加速度限制 | 降低让启停更平滑 |
| `acc_lim_y` | 0.1 m/s² | 横向加速度限制 | |
| `acc_lim_theta` | 1.5 rad/s² | 角加速度限制 | 降低让转弯更平滑 |
| `min_turning_radius` | 0.0 | 最小转弯半径 | 0 = 可原地旋转（四足适用） |

### 2.2 目标到达判定

| 参数 | 当前值 | 说明 | 调节建议 |
|------|--------|------|----------|
| `xy_goal_tolerance` | **0.2 m** | 目标位置允许误差 | 越小精度越高但到达越慢。室内 0.1-0.15，室外 0.2-0.5 |
| `yaw_goal_tolerance` | **0.15 rad (≈8.6°)** | 目标朝向允许误差 | 越小对齐越精确但耗时更长 |
| `free_goal_vel` | false | true=到达时不强制减速到0 | 保持 false 确保稳定停止 |
| `trans_stopped_vel` | 0.05 m/s | 判定为停止的线速度阈值 | |
| `theta_stopped_vel` | 0.05 rad/s | 判定为停止的角速度阈值 | |
| `complete_global_plan` | false | true=必须走完全局路径 | false=到达容差内即停止 |
| `arrival_debounce_cycles` | 10 | 到达防抖周期数（10Hz=1秒） | 增加防误判，减少防抖动 |
| `arrival_hold_cycles` | 15 | 到达后保持控制周期数（1.5秒） | 确保机器人稳定停住 |

### 2.3 轨迹优化

| 参数 | 当前值 | 说明 | 调节建议 |
|------|--------|------|----------|
| `controller_frequency` | 10 Hz | 控制频率 | 越高轨迹越平滑但 CPU 开销大 |
| `dt_ref` | 0.5 s | 参考轨迹点时间间隔 | 增大=轨迹更稀疏但视野更长 |
| `dt_hysteresis` | 0.1 s | 轨迹点时间间隔滞后 | 防止频繁增减轨迹点 |
| `min_samples` | 3 | 最少轨迹点数 | |
| `max_samples` | 100 | 最多轨迹点数 | 减小降低计算量 |
| `max_global_plan_lookahead_dist` | 5.0 m | 全局路径前视距离 | 增大=看得更远，减小=更专注近处 |
| `global_plan_prune_distance` | 0.5 m | 途经点距离阈值 | |
| `global_plan_viapoint_sep` | 0.3 m | 途经点采样间隔 | 越小轨迹越精细 |
| `force_reinit_new_goal_dist` | 0.5 m | 新目标超过此距离才重新初始化 | |
| `force_reinit_new_goal_angular` | 0.78 rad | 新目标角度超过此值重新初始化 | |

### 2.4 优化权重

| 参数 | 当前值 | 说明 | 调节建议 |
|------|--------|------|----------|
| `weight_kinematics_nh` | 100 | 非完整运动学约束权重 | 四足可适当降低 |
| `weight_kinematics_forward_drive` | 20 | 前向驱动偏好权重 | 鼓励向前行驶 |
| `weight_optimaltime` | 1 | 最短时间优化权重 | 增大=更快但可能更激进 |
| `weight_shortest_path` | 9 | 最短路径优化权重 | 增大=更紧贴全局路径 |
| `weight_viapoint` | 1 | 途经点约束权重 | |
| `weight_prefer_rotdir` | 50 | 旋转方向偏好权重 | 避免不必要的绕圈 |
| `weight_linear_angular` | 3 | 线速度-角速度耦合权重 | |
| `weight_linear_angular_times` | 1 | 耦合权重放大倍数 | |
| `no_inner_iterations` | 10 | 内层优化迭代次数 | 增大提高精度但降低频率 |
| `no_outer_iterations` | 8 | 外层优化迭代次数 | |
| `penalty_epsilon` | 0.05 | 惩罚项近似精度 | |

### 2.5 足迹与障碍物

| 参数 | 当前值 | 说明 | 调节建议 |
|------|--------|------|----------|
| `min_obstacle_dist` | 0.15 m | 最小障碍物距离 | 增大=更保守 |
| `inflation_dist` | 0.15 m | 膨胀距离 | |
| `dynamic_obstacle_inflation_dist` | 0.2 m | 动态障碍膨胀 | |
| `include_dynamic_obstacles` | true | 包含动态障碍物 | |
| `include_costmap_obstacles` | false | 包含代价地图障碍 | false=仅用点云障碍 |
| `obstacle_proximity_ratio_max_vel` | 0.7 | 近障碍物速度缩放 | 越小越慢 |
| `obstacle_proximity_lower_bound` | 0.2 m | 接近障碍下限 | |
| `obstacle_proximity_upper_bound` | 0.6 m | 接近障碍上限 | |

## 8. 常见调参场景

### 8.1 导航到不了目标点

| 症状 | 可能原因 | 调节方向 |
|------|----------|----------|
| 在目标附近来回摆动 | 到达容差太小 | 增大 `xy_goal_tolerance` 到 0.3-0.5m |
| 一直显示"对齐中" | 角度容差太小 | 增大 `yaw_goal_tolerance` 到 0.3-0.5 rad |
| 到达但状态未切换 | 到达防抖太短 / 有残余速度 | 增大 `arrival_debounce_cycles` |
| 目标被障碍物围住 | 膨胀太大 / 目标在障碍区内 | 减小 `inflation_radius` 或移动目标点 |

### 8.2 机器人撞障碍物

| 症状 | 可能原因 | 调节方向 |
|------|----------|----------|
| 擦边过窄通道 | 膨胀半径太小 | 增大 `inflation_radius` 到 0.3-0.5m |
| 过于激进贴近障碍 | 代价衰减太快 | 减小 `cost_scaling_factor` 到 3-5 |
| 检测不到低矮障碍 | 最小高度太高 | 降低 `min_obstacle_height`（负值如 -0.15） |
| 检测不到高处障碍 | 最大高度太低 | 增大 `max_obstacle_height` |
| 障碍物检测范围不够 | `obstacle_range` 太小 | 增大到 5m |
| 雷达点云噪声误检 | `voxel_min_points` 太小 | 增大到 5 |

### 8.3 定位漂移 / 丢失

| 症状 | 可能原因 | 调节方向 |
|------|----------|----------|
| 定位频繁跳变 | NDT 校正门控太松 | 减小 `max_correction_dist`（如 0.5m） |
| | | 减小 `max_correction_angle`（如 0.3 rad） |
| 定位精度不够 | NDT 分辨率太粗 | 减小 `ndt_resolution` 到 0.2-0.3m |
| 定位延迟高 | 点云太密 | 增大 `downsample_resolution` 到 0.2m |
| 特征少区域丢失 | NDT 搜索半径太小 | 增大 `ndt_neighbor_search_radius` |
| 机器人自身点云干扰定位 | CropBox 范围太小 | 检查 `navigation.launch` 中 CropBox 参数 |
| voxel_grid 不更新导致定位状态丢失 | STVL 层异常 | 检查 Livox 雷达驱动 / STVL 层 |

### 8.4 运动不流畅

| 症状 | 可能原因 | 调节方向 |
|------|----------|----------|
| 刹车太猛 | 加速度太大 | 降低 `acc_lim_x`（0.3-0.5 m/s²） |
| 转弯抖动 | 角速度/角加速度太大 | 降低 `max_vel_theta`（0.8-1.0 rad/s） |
| | | 降低 `acc_lim_theta`（0.5-0.8 rad/s²） |
| 频繁停-走 | 代价图噪声 | 增大 `voxel_min_points` 到 5-10 |
| | | 增大 `voxel_decay` |
| 路径震荡 | 频繁重新规划 | 增大 `dt_ref`、降低 `controller_frequency` |
| 原地转圈寻找方向 | 旋转方向权重不当 | 调整 `weight_prefer_rotdir` |

### 8.5 多点导航（任务模式）异常

| 症状 | 可能原因 | 调节方向 |
|------|----------|----------|
| 第一个点后不继续 | 到达判定未触发 | 增大 `xy_goal_tolerance` |
| 卡在某个点不动 | 到达判定未触发/规划失败 | 增大 `xy_goal_tolerance` 或增大 `controller_patience` |
| 跳过某个导航点 | Task.py 超时机制 | 检查 TASK_DATA JSON 文件顺序与格式 |

### 8.6 速度与效率调节

| 目标 | 调节方向 |
|------|----------|
| 更快到达（牺牲平稳） | ↑ `max_vel_x` ↑ `acc_lim_x` ↑ `max_vel_theta` ↓ `weight_shortest_path` |
| 更平稳（牺牲速度） | ↓ `max_vel_x` ↓ `acc_lim_x` ↑ `dt_ref` ↑ `weight_shortest_path` |
| 紧贴路径（不走捷径） | ↑ `weight_shortest_path` ↑ `weight_viapoint` ↓ `weight_optimaltime` |
| 更快转弯 | ↑ `max_vel_theta` ↑ `acc_lim_theta` ↓ `weight_kinematics_forward_drive` |
