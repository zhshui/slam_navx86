# 部署运维手册

> 版本：v1.0 | 日期：2026-07-23

---

## 1. 系统架构

```
机器人端 (Ubuntu 20.04 + ROS Noetic)
├── Gateway (Express, 端口 8080)   — Web API + 进程管理
├── rosbridge (端口 9090)           — ROS ↔ WebSocket 桥接
├── move_base (导航)                — 路径规划 + 控制
├── hdl_localization (定位)         — NDT 点云配准
├── faster-lio (建图)               — 激光 SLAM
├── livox_ros_driver2 (雷达驱动)    — MID-360 数据采集
└── go2_cmd_vel (运控)             — 机器人运动控制
```

## 2. 日常运维

### 2.1 启动顺序

```bash
# 步骤1: 启动 rosbridge（必须先启动）
roslaunch rosbridge_server rosbridge_websocket.launch &

# 步骤2: 启动 Gateway
cd ~/go2_nav/ros_web_gui_app/gateway
npm start &

# 步骤3 (可选): 启动雷达驱动（如果未自动启动）
roslaunch livox_ros_driver2 msg_MID360.launch &

# 步骤4: 通过 Web 界面操作
# - 启动雷达 → /api/lidar/start
# - 启动运控 → /api/motion/start
# - 开始建图 → /api/mapping/start
# - 开始导航 → /api/nav/command {start}
```

### 2.2 停止顺序

```bash
# 步骤1: 通过 Web 界面停止导航/建图
# 步骤2: 关闭 Gateway (Ctrl+C)
# 步骤3: 关闭 rosbridge (Ctrl+C)
# 步骤4 (可选): 关闭雷达驱动
```

### 2.3 健康检查

```bash
# 检查 Gateway 是否运行
curl http://127.0.0.1:8080/api/health

# 检查关键 ROS 节点
rosnode list | grep -E "move_base|hdl_localization|livox"

# 检查关键 ROS 话题
rostopic list | grep -E "/cmd_vel|/move_base|/tf"

# 检查 CPU/内存
htop

# 检查磁盘空间
df -h
```

### 3.2 Gateway 日志

Gateway 日志输出到 console (stdout)，建议重定向到文件：

```bash
cd ~/go2_nav/ros_web_gui_app/gateway
npm start 2>&1 | tee gateway.log
```

关键日志标识：
- `[gateway]` — Gateway 业务日志
- `[rosAdapter]` — ROS 连接与话题日志

## 4. 故障排查

### 4.1 Gateway 无法启动

| 症状 | 可能原因 | 解决 |
|------|----------|------|
| 端口 8080 被占用 | 已有 Gateway 实例 | `lsof -i :8080` → kill |
| npm start 报错 | 依赖未安装 | `cd gateway && npm install` |
| 数据库损坏 | SQLite 文件损坏 | 删除 `data/nav_web.sqlite` 重启（地图数据丢失） |

### 4.2 rosbridge 连接失败

| 症状 | 可能原因 | 解决 |
|------|----------|------|
| Gateway 日志显示 rosbridge 断开 | rosbridge 未启动 | 检查 `roslaunch rosbridge_server` |
| Web 端无遥测数据 | rosbridge 连接断开 | 重启 rosbridge |
| rosbridge 报内存不足 | 大数据传输 | 检查是否有大尺寸地图通过 rosbridge 传输 |

### 4.3 导航异常

| 症状 | 可能原因 | 解决 |
|------|----------|------|
| move_base 无法启动 | 环境变量未 source | `source ~/go2_nav/lite_cog/nav/devel/setup.bash` |
| 规划失败 | 代价地图有误 | 检查雷达数据，清除代价地图 |
| TEB 崩溃 | 参数不合理 | 检查 `teb_local_planner_params.yaml` |
| /cmd_vel 无输出 | move_base 未连接 action server | 检查 `rostopic hz /cmd_vel` |

### 4.4 定位异常

| 症状 | 可能原因 | 解决 |
|------|----------|------|
| 定位丢失 | PCD 未加载或路径错误 | 检查 `hdl_localization.launch` 中 `globalmap_pcd` |
| 定位跳变 | NDT 校正门控太松 | 减小 `max_correction_angle` |
| hdl_localization 不启动 | 编译未成功 | `cd nav && catkin_make` |

### 4.5 雷达异常

| 症状 | 可能原因 | 解决 |
|------|----------|------|
| 无点云数据 | 雷达未连接或驱动未启动 | 检查 USB/网线，检查驱动 |
| 点云稀疏 | 雷达脏污或遮挡 | 清洁雷达窗口 |
| 话题无数据 | topic 名称不匹配 | `rostopic list` 检查 |

## 5. 备份与恢复

### 5.1 备份内容

```bash
# 备份整个系统配置和数据
BACKUP_DIR="/backup/nav_$(date +%Y%m%d)"
mkdir -p $BACKUP_DIR

# 地图文件
cp -r ~/go2_nav/lite_cog/system/map $BACKUP_DIR/

# 配置文件
cp -r ~/go2_nav/lite_cog/nav/src/navigation/config $BACKUP_DIR/

# 数据库
cp ~/go2_nav/ros_web_gui_app/gateway/data/nav_web.sqlite $BACKUP_DIR/

# 环境变量
env > $BACKUP_DIR/env.txt
```

### 5.2 恢复

```bash
# 恢复地图
cp -r $BACKUP_DIR/map ~/go2_nav/lite_cog/system/

# 恢复配置
cp -r $BACKUP_DIR/config ~/go2_nav/lite_cog/nav/src/navigation/

# 恢复数据库
cp $BACKUP_DIR/nav_web.sqlite ~/go2_nav/ros_web_gui_app/gateway/data/

# 重启 Gateway
```

### 5.3 自动备份脚本

```bash
#!/bin/bash
# /etc/cron.daily/nav_backup.sh
BACKUP_DIR="/backup/nav_$(date +%Y%m%d_%H%M)"
mkdir -p $BACKUP_DIR
cp -r ~/go2_nav/lite_cog/system/map $BACKUP_DIR/
cp ~/go2_nav/ros_web_gui_app/gateway/data/nav_web.sqlite $BACKUP_DIR/
# 保留最近 7 天
find /backup -maxdepth 1 -name "nav_*" -mtime +7 -exec rm -rf {} \;
```

## 6. 性能优化

### 6.1 降低 CPU 使用率

```yaml
# teb_local_planner_params.yaml
controller_frequency: 5          # 从 10 降到 5
no_inner_iterations: 5           # 从 10 降到 5
no_outer_iterations: 4           # 从 8 降到 4
max_samples: 50                  # 从 100 降到 50
```

### 6.2 降低内存使用

```yaml
# common_costmap_params.yaml
voxel_size: 0.1                  # 从 0.05 增大
resolution: 0.2                  # 从 0.1 增大
```

### 6.3 提升定位速度

```xml
<!-- hdl_localization.launch -->
<param name="ndt_resolution" value="1.0" />         <!-- 从 0.5 增大 -->
<param name="downsample_resolution" value="0.2" />  <!-- 从 0.1 增大 -->
```

## 7. 安全管理

### 7.1 防火墙配置

```bash
# 仅开放需要的端口
sudo ufw default deny incoming
sudo ufw allow 22/tcp      # SSH
sudo ufw allow 8080/tcp    # Gateway Web
sudo ufw allow 9090/tcp    # rosbridge (如仅本机则不需要)
sudo ufw enable
```

### 7.2 修改默认密码

1. 登录 Web 界面
2. 进入「用户管理」（需 admin 角色）
3. 修改 admin 用户密码

或通过 SQLite 直接修改：
```bash
# 生成新密码哈希 (通过 Node.js)
node -e "console.log(require('bcryptjs').hashSync('新密码', 10))"
# 更新数据库
sqlite3 data/nav_web.sqlite "UPDATE users SET password_hash='<哈希值>' WHERE username='admin';"
```

### 7.3 日志清理

```bash
# ROS 日志（自动轮转）
# 默认保留在 ~/.ros/log/

# 手动清理
find ~/.ros/log/ -mtime +30 -exec rm -rf {} \;
```

## 8. ROS 参数运行时调节

### 8.1 dynamic_reconfigure

```bash
# 查看 TEB 可调参数
rosrun dynamic_reconfigure dynparam list /move_base/TebLocalPlannerROS

# 运行时修改
rosrun dynamic_reconfigure dynparam set /move_base/TebLocalPlannerROS xy_goal_tolerance 0.3
rosrun dynamic_reconfigure dynparam set /move_base/TebLocalPlannerROS min_obstacle_dist 0.25
```

### 8.2 rosparam

```bash
# 修改 STVL 参数
rosparam set /move_base/local_costmap/stvl_obstacle_layer/livox_lidar/obstacle_range 5.0
rosparam set /move_base/global_costmap/stvl_obstacle_layer/livox_lidar/obstacle_range 5.0
```

### 8.3 重启 move_base（不重启定位）

```bash
# 仅重启 move_base 节点
rosnode kill /move_base
roslaunch navigation navigation.launch  # 或通过 restart_move_base.sh
```

## 11. 常用命令速查

```bash
# 系统状态概览
curl http://127.0.0.1:8080/api/snapshot

# 查看当前激活地图
sqlite3 data/nav_web.sqlite "SELECT name FROM maps WHERE active=1;"

# 查看地图列表
sqlite3 data/nav_web.sqlite "SELECT name, created_at FROM maps ORDER BY created_at DESC;"

# 查看导航点
sqlite3 data/nav_web.sqlite "SELECT name, x, y FROM nav_points ORDER BY created_at;"

# 清除所有代价地图
rosservice call /move_base/clear_costmaps "{}"

# 手动设置初始位姿
rostopic pub /initialpose geometry_msgs/PoseWithCovarianceStamped "header: {frame_id: map}
pose: {pose: {position: {x: 0, y: 0, z: 0}, orientation: {x: 0, y: 0, z: 0, w: 1}}}"

# 手动发送导航目标
rostopic pub /move_base_simple/goal geometry_msgs/PoseStamped "header: {frame_id: map}
pose: {position: {x: 1, y: 2, z: 0}, orientation: {x: 0, y: 0, z: 0.707, w: 0.707}}"
```
