### 2. 模块划分

| 模块 | 技术栈 | 职责 |
|------|--------|------|

## 第二部分：详细设计

### 4. Gateway 详细设计

#### 4.1 核心类与模块

| 模块 | 文件 | 说明 |
|------|------|------|
| 应用入口 | `index.ts` | Express 服务器、WebSocket、API 路由 |
| 状态管理 | `state.ts` | 全局运行时状态 (runtimeState) |
| 数据库 | `db.ts` | SQLite 数据库初始化与迁移 |
| 鉴权 | `auth.ts` | JWT 签发/验证、角色权限 |
| ROS 适配器 | `rosAdapter.ts` | rosbridge 连接、话题订阅/发布 |

#### 4.2 进程管理设计

Gateway 管理以下子进程：

| 进程 | 启动方式 | 状态跟踪 |
|------|----------|----------|
| SLAM (faster-lio) | `spawn('bash', [SLAM_SCRIPT])` | `mappingStatus` |
| Navigation (move_base+hdl) | `spawn('bash', [NAV_SCRIPT])` | `navStatus` |
| Task (Task.py) | `spawn('bash', ..., [TASK_SCRIPT])` | `navStatus` |
| LiDAR Driver | `spawn('bash', [LIDAR_SCRIPT])` | `lidarStatus` |
| Motion (go2 SDK) | `spawn('bash', [MOTION_SCRIPT])` | `motionStatus` |

**防旧回调机制**：通过 `navGeneration` 递增计数器，旧进程的 `exit` 事件被忽略。

#### 4.3 遥测差分推送

`setInterval` 每 200ms 执行差分检测，仅发送变化字段：

```typescript
// 订阅话题 → 更新 runtimeState → 差分检测 → WebSocket broadcast
subscribed topics:
  /tf → runtimeState.tfPose
  /move_base/GlobalPlanner/plan → runtimeState.globalPlan
  /move_base/TebLocalPlannerROS/local_plan → runtimeState.localPlan
  /move_base/local_costmap/stvl_obstacle_layer/voxel_grid → runtimeState.voxelGrid
```

#### 4.4 地图格式转换

PGM (Portable Gray Map) → PNG 转换在 Gateway 内部完成（零依赖，纯 zlib 压缩）：

```
PGM raw pixels → PNG (IHDR + IDAT + IEND) → /static/maps/live_map.png
占用栅格值映射: 100(黑色) → PGM 0, 0(白色) → PGM 254, -1(未知) → PGM 205
```

大尺寸地图（≥200万栅格）不通过 WebSocket 发送 raw data，前端通过 HTTP 加载 PNG 图片。

### 5. 导航详细设计

#### 5.1 全局规划器 (GlobalPlanner)

- **算法**：Dijkstra（`use_dijkstra: true`）
- **代价地图**：global_costmap (100×100 格, 分辨率 0.1m = 10m×10m)
- **插件链**：`static_layer` → `stvl_obstacle_layer` → `sob_layer` (膨胀)

#### 5.2 局部规划器 (TebLocalPlannerROS)

- **控制频率**：10 Hz
- **轨迹优化**：基于 G²O 图优化的时间弹性带
- **代价地图**：local_costmap (10×10 格 = 1m×1m)

#### 5.3 障碍物感知 (STVL)

```
Livox MID-360 点云 (360°×32°, 10Hz)
     │
     ▼ CropBox 过滤（剔除机器人自身 30cm 内的点）
     │
/ivox/lidar_nav
     │
     ▼ STVL 体素化 (voxel_size=0.05m)
     │
     ▼ 降采样投影到 2D 代价地图
     │
obstacle_range=3.0m, 高度范围 -0.15m~0.6m
```

#### 5.4 到达判定状态机

```
     收到目标
        │
        ▼
   ┌─ 运动中 ──────────────────────────────────────┐
   │                                               │
   ▼ (dist_to_goal >= 0.2m)                        │
   │                                               │
   ├─ 阻塞检测 ──(否)──► 运动中                    │
   │   │ 平均速度 < 0.03m/s                         │
   │   │ 持续 > 10s                                 │
   │   └─(是)──► 阻塞                               │
   │                                               │
   ▼ (dist_to_goal < 0.2m)                         │
   │                                               │
   ├─ 到达判定 ──(位置+朝向容差)──► 对齐中          │
   │   │ 静止 + 到达防抖 1s                         │
   │   └─(是)──► 到达                               │
   └───────────────────────────────────────────────┘
```

#### 5.5 恢复行为链

```
导航卡住 → 1. 清除局部代价地图 (3m半径)
         → 2. 原地旋转重试
         → 3. 清除全局代价地图
         → 4. 再次旋转重试
```

### 6. 定位详细设计

#### 6.1 HDL Localization 架构

```
PCD 全局地图 ──► GlobalmapServer (降采样 0.1m)
                        │
                        ▼
                    NDT 体素网格 (分辨率 0.5m)
                        │
                        ▲
LiDAR 点云 ──► 降采样 (0.1m) ──┘
                        │
                        ▼
                    NDT 配准 (DIRECT7 搜索)
                        │
                        ▼
                    UKF 滤波
                        │
                    ┌───┴───┐
                    │ 质量门控 │
                    │ 位移<100m │
                    │ 角度<0.8rad│
                    └───┬───┘
                        │
                        ▼
                    TF: map → odom → base_link
```

#### 6.2 全局重定位 (hdl_global_localization)

当定位丢失时自动触发：
1. BBS (Branch-and-Bound Search) 生成候选位姿
2. FPFH 特征匹配验证
3. RANSAC/TEASER 精配准
4. 将最佳候选注入 UKF

### 7. 前端详细设计

#### 7.1 组件树

```
App
├── LoginPage          (登录)
├── GatewayProvider    (全局状态 + WebSocket)
├── Dashboard          (仪表盘)
├── LayerSettingsPanel (图层/参数面板)
│   ├── MappingControl (建图控制)
│   ├── NavControl     (导航控制 + 定位状态)
│   ├── MotionControl  (运动控制)
│   ├── LiDARControl   (雷达控制)
│   └── NavPointManager(导航点管理)
├── MapView            (地图显示与交互)
│   ├── 2D Nav Goal    (点击设目标 + 拖拽调朝向)
│   └── 2D Pose Estimate (重定位)
├── MapManager         (地图列表/切换/删除)
└── VirtualObstacles   (虚拟障碍物)
```

#### 7.2 地图交互设计

| 操作 | 实现 |
|------|------|
| 拖拽平移 | Three.js OrbitControls |
| 滚轮缩放 | OrbitControls |
| 点击设目标 | Raycaster → 3D 坐标 → `/api/nav/simple-goal` |
| 拖拽调朝向 | mousedown 记录位置 → mousemove 计算角度 → mouseup 发布 |
| 重定位 | 同上，发布到 `/api/initialpose` |

#### 7.3 定位状态判断（前端）

```typescript
const voxelAge = Date.now() - lastVoxelAt;
if (voxelAge < 3000) return "🟢 就绪";
const tfAge = Date.now() - lastTfAt;
if (tfAge < 2000) return "🟡 仅TF";
return "🔴 丢失";
```

### 8. 关键时序

#### 8.1 单点导航流程

```
Web ──POST /api/nav/simple-goal──► Gateway ──publish /move_base_simple/goal──► ROS
                                                                                  │
                                                                                  ▼
                                                                           move_base 接收目标
                                                                                  │
                                                                                  ▼
                                                                     GlobalPlanner 规划全局路径
                                                                                  │
                                                                                  ▼
                                                                   TebLocalPlanner 生成轨迹
                                                                                  │
                                                                                  ▼
                                                                     /cmd_vel ──► Go2 执行
                                                                                  │
Gateway ◄── rosbridge ── TF / GlobalPlan / LocalPlan ◄────────────────────────────┘
   │
   ▼ WebSocket
Web 显示位姿 + 路径
```

#### 8.2 多点导航流程

```
Web ──POST /api/topology/save──► Gateway ──写 JSON 文件──► TASK_DATA_DIR
                                                               │
Web ──POST /api/nav/command {start}──► Gateway ──spawn──► Task.py
                                                               │
                                                     Task.py 循环读取 JSON
                                                               │
                                                     for each point:
                                                       publish /move_base_simple/goal
                                                       等待到达 → 下一个点
```

### 9. 配置管理

所有 ROS 参数配置位于 `lite_cog/nav/src/navigation/config/`：

| 文件 | 用途 |
|------|------|
| `teb_local_planner_params.yaml` | TEB 局部规划器全部参数 |
| `common_costmap_params.yaml` | 代价地图通用参数（STVL/膨胀） |
| `global_costmap_params.yaml` | 全局代价地图尺寸与插件 |
| `local_costmap_params.yaml` | 局部代价地图尺寸与插件 |
| `global_planner_params.yaml` | 全局规划器参数 |
| `move_base_params.yaml` | move_base 控制与恢复行为 |

Gateway 通过 `POST /api/nav/param/reconfigure` 和 `POST /api/nav/param/rosparam` 动态修改参数，并通过 `sed` 同步写入 YAML 文件保证重启后持久化。
