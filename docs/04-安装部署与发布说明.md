## 第一部分：系统安装部署

### 1. 系统架构概览

**核心模块说明：**

| 模块 | 功能 | 端口/协议 | 启动方式 |
|------|------|-----------|----------|
| `roscore` | ROS 核心通信 | TCP 11311 | systemd 自启动 |
| `rosbridge` | ROS ↔ WebSocket 桥接 | WebSocket 9090 | systemd 自启动 |
| `Gateway` | Web API + 进程管理 | HTTP 8080 | systemd 自启动 |
| `hdl_localization` | NDT 点云配准定位 | ROS topic | Web 界面触发 |
| `move_base` | 全局+局部路径规划 | ROS action | Web 界面触发 |
| `faster-lio` | 激光 SLAM 建图 | ROS topic | Web 界面触发 |
| `Task.py` | 多点导航任务编排 | Python进程 | Web 界面触发 |
| `go2_cmd_vel` | 机器人运动控制 | ROS topic | Web 界面触发 |
| `livox_ros_driver2` | MID-360 雷达驱动 | ROS topic | Web 界面触发 |

### 4. 全新机器从零部署

> 以下步骤假设你有一台刚装好 Ubuntu 20.04 的 x86 工控机，所有操作以 `robot` 用户身份执行。

#### 4.1 系统初始化

```bash
# 1. 更新系统到最新
sudo apt update && sudo apt upgrade -y

# 2. 安装基础工具
sudo apt install -y curl wget git vim htop net-tools openssh-server

# 3. 设置时区
sudo timedatectl set-timezone Asia/Shanghai

# 4. 确认系统版本
lsb_release -a
# 应输出: Ubuntu 20.04.x LTS
```

#### 4.2 安装 ROS Noetic

```bash
# 1. 添加 ROS 源
sudo sh -c 'echo "deb http://packages.ros.org/ros/ubuntu focal main" > /etc/apt/sources.list.d/ros-latest.list'

# 2. 添加密钥
curl -s https://raw.githubusercontent.com/ros/rosdistro/master/ros.asc | sudo apt-key add -
sudo apt update

# 3. 安装完整桌面版 ROS
sudo apt install -y ros-noetic-desktop-full

# 4. 初始化 rosdep
sudo rosdep init
rosdep update

# 5. 将 ROS 环境写入 bashrc
echo "source /opt/ros/noetic/setup.bash" >> ~/.bashrc
source ~/.bashrc

# 6. 验证安装（新终端运行，Ctrl+C 退出即通过）
roscore
```

#### 4.3 安装 ROS 依赖包

```bash
# 导航核心 + 建图 + 工具
sudo apt install -y \
  ros-noetic-navigation \
  ros-noetic-teb-local-planner \
  ros-noetic-move-base \
  ros-noetic-global-planner \
  ros-noetic-map-server \

  ros-noetic-costmap-converter \
  ros-noetic-mbf-costmap-core \
  ros-noetic-mbf-abstract-core

# 编译工具链

  build-essential cmake git \
  python3-pip python3-catkin-tools \
  libpcl-dev libeigen3-dev \
  libgoogle-glog-dev libsuitesparse-dev
```

#### 4.4 安装 Node.js 20（nvm 方式）

```bash
# 安装 nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.0/install.sh | bash
```


### 7. Systemd 开机自启动配置

> 本章节实现：**机器人上电后自动启动 roscore → rosbridge → Gateway + 雷达驱动**。
> 此后通过 Web 界面一键触发建图/导航即可，无需 SSH 登录。

#### 7.1 创建 ROS 公用环境脚本

```bash
sudo tee /etc/ros/env.sh << 'EOF'
#!/bin/bash
# /etc/ros/env.sh — 供 systemd 服务加载的 ROS 环境

export ROS_MASTER_URI=http://127.0.0.1:11311
export ROS_HOSTNAME=127.0.0.1
export ROS_IP=127.0.0.1

source /opt/ros/noetic/setup.bash
source /home/robot/go2_nav/lite_cog/drivers/mid360_ws/devel/setup.bash
source /home/robot/go2_nav/go2_SDK_ws/devel/setup.bash
source /home/robot/go2_nav/lite_cog/nav/devel/setup.bash
source /home/robot/go2_nav/SC-FAST-LIO-main/devel/setup.bash
source /home/robot/go2_nav/lite_cog/pipeline/devel/setup.bash
EOF

sudo chmod +x /etc/ros/env.sh
```

#### 7.2 roscore 服务

```bash
sudo tee /etc/systemd/system/roscore.service << 'EOF'
[Unit]
Description=ROS Master (roscore)
After=network.target
Wants=network.target

[Service]
Type=simple
User=robot
EnvironmentFile=/etc/ros/env.sh
ExecStart=/opt/ros/noetic/bin/roscore
Restart=on-failure
RestartSec=3
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
EOF
```

#### 7.3 rosbridge 服务（依赖 roscore）

```bash
sudo tee /etc/systemd/system/rosbridge.service << 'EOF'
[Unit]
Description=ROS Bridge WebSocket Server (:9090)
After=roscore.service
Requires=roscore.service

[Service]
Type=simple
User=robot
EnvironmentFile=/etc/ros/env.sh
# 等待 roscore 完全就绪（最多30秒）
ExecStartPre=/bin/bash -c 'for i in $(seq 1 30); do rostopic list &>/dev/null && exit 0; sleep 1; done; exit 1'
ExecStart=/opt/ros/noetic/bin/roslaunch rosbridge_server rosbridge_websocket.launch
Restart=always
RestartSec=5
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
EOF
```

#### 7.4 Gateway 服务（依赖 rosbridge）

```bash
# 先确定 Node.js 可执行文件的绝对路径
NODE_BIN=$(which node)
echo $NODE_BIN   # 记录此路径，例如 /home/robot/.nvm/versions/node/v20.19.0/bin/node

sudo tee /etc/systemd/system/nav-gateway.service << EOF
[Unit]
Description=Navigation Gateway (Web API, :8080)
After=rosbridge.service
Requires=rosbridge.service

[Service]
Type=simple
User=robot
WorkingDirectory=/home/robot/go2_nav/ros_web_gui_app/gateway
EnvironmentFile=/home/robot/go2_nav/ros_web_gui_app/gateway/.env
# 等待 rosbridge 端口就绪（最多20秒）
ExecStartPre=/bin/bash -c 'for i in \$(seq 1 20); do ss -tlnp | grep -q 9090 && exit 0; sleep 1; done; exit 1'
ExecStart=${NODE_BIN} dist/index.js
Restart=always
RestartSec=5
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
EOF
```

#### 7.5 启用服务并立即启动

```bash
# 重新加载 systemd
sudo systemctl daemon-reload

# 启用开机自启
sudo systemctl enable roscore.service
sudo systemctl enable rosbridge.service
sudo systemctl enable nav-gateway.service

# 立即启动（按顺序）
sudo systemctl start roscope.service
sleep 3
sudo systemctl start rosbridge.service
sleep 2
sudo systemctl start nav-gateway.service

# 查看状态
sudo systemctl status roscope.service --no-pager -l
sudo systemctl status rosbridge.service --no-pager -l
sudo systemctl status nav-gateway.service --no-pager -l
```

#### 7.6 常用管理命令速查

```bash
# ─── 状态查看 ───
sudo systemctl status roscope.service
sudo systemctl status rosbridge.service
sudo systemctl status nav-gateway.service

# ─── 启动 / 停止 / 重启 ───
sudo systemctl start nav-gateway.service
sudo systemctl stop nav-gateway.service
sudo systemctl restart nav-gateway.service

# ─── 查看实时日志 ───
sudo journalctl -u roscope.service   -f   # 实时滚动
sudo journalctl -u rosbridge.service -f
sudo journalctl -u nav-gateway.service -f

# ─── 查看最近50行日志 ───
sudo journalctl -u nav-gateway.service -n 50 --no-pager

# ─── 禁用/启用开机自启 ───
sudo systemctl disable nav-gateway.service
sudo systemctl enable nav-gateway.service
```

### 10. 故障排查

#### 10.1 编译阶段

| 现象 | 原因 | 解决 |
|------|------|------|
| `teb_local_planner` 编译失败 | 缺少依赖包 | `sudo apt install ros-noetic-costmap-converter ros-noetic-mbf-abstract-core` |
| `catkin_make` 找不到 ROS | 未 source setup.bash | `source /opt/ros/noetic/setup.bash` |
| `npm install` 失败 (sqlite3) | 缺少 libsqlite3-dev | `sudo apt install libsqlite3-dev` |
| `npm run build` 失败 | TypeScript 编译错误 | 查看具体错误信息，通常是类型不匹配 |

#### 10.2 启动阶段

| 现象 | 原因 | 解决 |
|------|------|------|
| `roscore.service` 启动失败 | 11311 端口占用 | `sudo lsof -i :11311` 查看占用进程并 kill |
| `rosbridge.service` 启动失败 | roscore 未就绪 | ExecStartPre 有30秒等待，检查 roscore 是否正常 |
| `nav-gateway.service` 启动失败 | 端口 8080 被占用 | `sudo lsof -i :8080` |
| Gateway 启动但无响应 | `.env` 中 `ROS_MODE=mock` | 改为 `ROS_MODE=rosbridge` |
| Web 页面空白 | 前端未构建 | `cd ~/go2_nav/ros_web_gui_app && npm run build` |

#### 10.3 运行阶段

| 现象 | 原因 | 解决 |
|------|------|------|
| 雷达无点云数据 | 驱动未启动或硬件连接问题 | 检查网线连接，`rostopic hz /livox/lidar` |
| 定位一直丢失 | PCD 地图未加载 | 检查 `active/current.yaml` 是否正确链接 |
| 导航规划失败 | 代价地图异常 | `rosservice call /move_base/clear_costmaps "{}"` |
| move_base 频繁重启 | TEB 参数不合理 | 检查 `teb_local_planner_params.yaml` |

#### 10.4 日志查看

```bash
# 各组件的日志位置
sudo journalctl -u roscope.service     # roscore 日志
sudo journalctl -u rosbridge.service   # rosbridge 日志
sudo journalctl -u nav-gateway.service # Gateway 日志

# ROS 节点日志

# 导航日志
tail -f ~/go2_nav/lite_cog/system/scripts/nav/logs/nav.log
```
