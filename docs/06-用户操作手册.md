# 用户操作手册

> 版本：v1.0 | 日期：2026-07-23

---

## 1. 系统登录

1. 打开浏览器，访问 `http://<机器人IP>:8080`
2. 输入用户名和密码（默认：`admin` / `admin123`）
3. 点击「登录」


---

## 2. 建图操作

### 3.1 开始建图

1. 确保机器人位于待建图区域的起点
2. 点击左侧面板「建图控制」→ **开始**
3. 遥控机器人缓慢遍历整个区域
4. 地图会实时显示在 MapView 中

### 3.2 停止建图与保存

1. 遍历完成后，点击「建图控制」→ **停止**
2. 系统自动保存 PCD 点云，弹出保存对话框
3. 输入地图名称，点击「保存」
4. 系统生成 2D 栅格地图（PGM）并关联 PCD

### 3.3 地图编辑（可选）

建图保存后可在「地图管理」中进入编辑器：
- **擦除模式**：点击拖拽擦除误检的障碍物区域
- **绘制模式**：点击拖拽添加障碍物
- **发布**：编辑完成后点击「发布」推送到导航系统

---

## 3. 导航操作

### 3.1 准备工作

开始导航前确保：
1. 已有保存好的地图（PCD + PGM）
2. 已切换到目标地图（地图管理 → 点击地图名 → 切换）
3. 雷达已启动（界面显示 🟢）
4. 运控已启动（界面显示 🟢）

### 3.2 单点导航

1. 在左侧面板确认「导航模式」为**单点**
2. 在地图上**点击**目标位置，拖拽调整朝向
3. 松开发布导航目标
4. 机器人自动规划路径并前往
5. 到达后状态显示「到达」

### 3.3 多点导航

1. 在地图编辑器中添加导航点：
   - 点击地图添加点位
   - 输入名称，调整位置和朝向
   - 点击「发布点位」保存
2. 在导航面板确认导航模式为**多点**
3. 点击「开始」
4. 机器人按顺序依次前往各点

### 3.4 导航中控制

| 操作 | 按钮 | 效果 |
|------|------|------|
| 暂停 | ⏸ 暂停 | 停止移动，保留目标 |
| 继续 | ▶ 继续 | 重新规划并继续 |
| 停止 | ⏹ 停止 | 清除目标，停止移动 |

### 3.5 导航状态说明

| 状态 | 含义 |
|------|------|
| 🟢 运动中 | 正常导航执行中 |
| 🟡 对齐中 | 已接近目标，正在调整朝向 |
| 🟠 阻塞 | 检测到卡住，尝试恢复 |
| 🔵 到达 | 已成功到达目标点 |

## 4. 定位状态

左侧面板显示实时定位质量：

| 状态 | 含义 | 建议操作 |
|------|------|----------|
| 🟢 就绪 | 定位正常 | 可以导航 |
| 🟡 仅TF | 仅 TF 正常，障碍物感知可能异常 | 检查雷达 |
| 🔴 丢失 | 定位丢失 | 手动重定位或移动到特征丰富区域 |

---

## 5. 重定位

当定位丢失时：

1. 点击工具栏的「重定位」按钮进入重定位模式
2. 在地图上**点住拖拽**设置机器人当前位置和朝向
3. 松开后自动发布初始位姿
4. 等待系统自动完成定位恢复

---

## 6. 地图管理

### 6.1 切换地图

1. 点击「地图管理」
2. 在地图列表中点击目标地图名称
3. 系统自动加载对应 PCD 并发布初始位姿

### 6.2 导入地图

1. 点击「导入地图」
2. 选择外部 PGM 文件（需配套 YAML）
3. 系统自动解析并加入地图列表

### 6.3 导出地图

1. 在地图列表中找到目标地图
2. 点击导出按钮
3. 下载 ZIP 文件（含 YAML + PGM + PCD）

---

## 7. 导航参数调节

在参数面板中可实时调整：

| 参数 | 作用 | 推荐范围 |
|------|------|----------|
| 到达容差 (m) | 判定到达的距离 | 0.1 - 0.5 |
| 障碍距离 (m) | 与障碍物的安全距离 | 0.1 - 0.5 |
| 障碍物范围 (m) | 雷达检测范围 | 2.0 - 5.0 |
| 膨胀半径 (m) | 障碍物膨胀大小 | 0.15 - 0.5 |
| 代价衰减 | 膨胀衰减速度 | 3 - 20 |
| 最小障碍高度 (m) | 最低障碍高度 | -0.2 - 0.2 |
| 最大障碍高度 (m) | 最高障碍高度 | 0.3 - 1.5 |

> 修改后自动保存到配置文件，重启后仍生效。

## 8. 虚拟障碍物

在地图编辑器中可以添加虚拟障碍物：
- **矩形**：选择矩形工具，在地图上拖拽绘制
- **圆形**：选择圆形工具，点击确定圆心，拖拽确定半径
- **多边形**：连续点击确定顶点，双击完成

虚拟障碍物会发布到 `/virtual_obstacles` 话题，被导航系统识别。

## 9. 常见问题

### Q1: 定位一直是"丢失"状态

**原因**：PCD 地图未加载，或当前环境与地图差异过大。
**解决**：检查是否已切换正确的地图；将机器人移动到特征丰富的区域。

### Q2: 导航目标设置后机器人不动

**原因**：定位未就绪，或运控未启动，或目标点在障碍物内。
**解决**：检查定位状态和运控状态；重新选择可行目标点。

### Q3: 机器人撞到障碍物

**原因**：障碍物检测范围/高度设置不当。
**解决**：增大 `obstacle_range`；调整 `min_obstacle_height` 和 `max_obstacle_height`。

### Q4: 导航中频繁卡住

**原因**：代价地图噪声或膨胀太小。
**解决**：增大 `inflation_radius`；增大 `voxel_min_points` 减少噪声。

### Q5: 建图完成后看不到地图

**原因**：建图未正常保存。
**解决**：重新建图并确保点击「保存」；检查 PCD 文件是否生成。

### Q6: Web 界面连接不上

**原因**：Gateway 未启动或网络不通。
**解决**：检查 Gateway 进程 (`ps aux | grep gateway`)；检查防火墙。
