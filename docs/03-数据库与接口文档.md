> 版本：v1.0 | 日期：2026-07-23

## 第一部分：数据库设计

### 1. 数据库选型

| 项目 | 说明 |
|------|------|
| 数据库 | SQLite 3 (better-sqlite3) |
| 文件位置 | `ros_web_gui_app/gateway/data/nav_web.sqlite` |
| 写入模式 | WAL (Write-Ahead Logging) |
| ORM | 无，直接 SQL |

### 2. ER 图

```
┌──────────┐       ┌──────────────┐
│  users   │       │    maps      │
├──────────┤       ├──────────────┤
│ id (PK)  │       │ id (PK)      │
│ username │       │ name (UQ)    │
│ role     │       │ yaml_path    │
│ pwd_hash │       │ pcd_path     │
│ created  │       │ created_at   │
└──────────┘       │ active       │

                          │ 1:N

          ▼               ▼               ▼
   ┌────────────┐ ┌──────────────┐ ┌──────────────────┐

   │ id (PK)    │ ├──────────────┤ ├──────────────────┤
```

### 3. 表结构详细定义

#### 3.1 users（用户表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `id` | TEXT | PK, NOT NULL | UUID |
| `username` | TEXT | UNIQUE, NOT NULL | 登录用户名 |
| `role` | TEXT | NOT NULL | `admin` 或 `operator` |
| `password_hash` | TEXT | NOT NULL | bcrypt 哈希 (cost=10) |
| `created_at` | TEXT | NOT NULL | ISO 8601 时间戳 |

**初始数据**：
```
username: admin, password: admin123, role: admin
```

#### 3.2 maps（地图表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `id` | TEXT | PK, NOT NULL | UUID |
| `name` | TEXT | UNIQUE, NOT NULL | 地图名称 |
| `yaml_path` | TEXT | NOT NULL | YAML 描述文件绝对路径 |
| `pcd_path` | TEXT | NOT NULL, DEFAULT '' | PCD 点云文件绝对路径 |
| `created_at` | TEXT | NOT NULL | ISO 8601 时间戳 |
| `active` | INTEGER | NOT NULL, DEFAULT 0 | 是否当前激活地图（0/1） |

**约束**：`active` 全局唯一（每次切换时先将全部置 0，再置目标为 1）。

#### 3.3 nav_points（导航点表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `id` | TEXT | PK, NOT NULL | UUID |
| `name` | TEXT | NOT NULL | 导航点名称 |
| `x` | REAL | NOT NULL | X 坐标 (map 坐标系) |
| `y` | REAL | NOT NULL | Y 坐标 (map 坐标系) |
| `yaw` | REAL | NOT NULL | 朝向角 (弧度) |
| `map_id` | TEXT | FK → maps.id | 关联地图 |
| `created_at` | TEXT | NOT NULL | ISO 8601 时间戳 |

#### 3.4 virtual_obstacles（虚拟障碍物表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `id` | TEXT | PK, NOT NULL | UUID |
| `name` | TEXT | NOT NULL | 障碍物名称 |
| `shape` | TEXT | NOT NULL | `rect` / `circle` / `polygon` |
| `data` | TEXT | NOT NULL | JSON 字符串，形状参数 |
| `enabled` | INTEGER | NOT NULL, DEFAULT 1 | 是否启用（0/1） |
| `map_id` | TEXT | FK → maps.id | 关联地图 |
| `created_at` | TEXT | NOT NULL | ISO 8601 时间戳 |

**data JSON 格式示例**：
```json
// rect
{"x": 1.0, "y": 2.0, "width": 0.5, "height": 0.3, "angle": 0}
// circle
{"x": 1.0, "y": 2.0, "radius": 0.3}
// polygon
{"points": [{"x": 0, "y": 0}, {"x": 1, "y": 0}, {"x": 0.5, "y": 1}]}
```

#### 3.5 运行时状态（内存，非持久化）

定义在 `state.ts` 的 `runtimeState` 对象中，通过 WebSocket 推送到前端：

| 字段 | 类型 | 说明 |
|------|------|------|
| `rosConnected` | boolean | rosbridge 连接状态 |
| `mappingStatus` | 'idle'\|'running'\|'stopped' | 建图状态 |
| `navStatus` | 'idle'\|'running'\|'paused'\|'stopped' | 导航状态 |
| `navMode` | 'none'\|'single'\|'multi' | 导航模式 |
| `navGoal` | {x,y,yaw}\|null | 当前导航目标 |
| `lidarStatus` | 'idle'\|'running'\|'stopped' | 雷达状态 |
| `motionStatus` | 'idle'\|'running'\|'stopped' | 运控状态 |
| `currentMapId` | string\|null | 当前激活地图 ID |
| `tfPose` | {x,y,yaw,frame} | 当前位姿 |
| `globalPlan` | {x,y}[] | 全局路径点 |
| `localPlan` | {x,y}[] | 局部路径点(TEB) |
| `voxelGrid` | {x,y}[] | 体素障碍点(限256点) |
| `hdlRunning` | boolean | hdl_localization 是否运行 |
| `lastVoxelAt` | ISO8601\|null | voxel_grid 最后更新时间 |
| `lastTfAt` | ISO8601\|null | TF 最后更新时间 |
| `mapUpdatedAt` | ISO8601\|null | 地图最后更新时间 |

## 第二部分：API 接口文档

### 4. 通用说明

**Base URL**：`http://<机器人IP>:8080`

**认证方式**：Bearer Token (JWT)
```
Authorization: Bearer <token>
```

**响应格式**：JSON

**角色权限**：`admin` > `operator`

---

### 5. 认证接口

#### POST /api/auth/login

登录获取 Token。

| 项目 | 说明 |
|------|------|
| 认证 | 无需 |
| Body | `{"username": "admin", "password": "admin123"}` |
| 成功 | `200 {"token": "...", "user": {...}}` |
| 失败 | `401 {"error": "Invalid credentials"}` |

#### GET /api/auth/me

获取当前用户信息。

| 项目 | 说明 |
|------|------|
| 认证 | 需要 |

---

### 6. 系统接口

#### GET /api/health

健康检查（无需认证）。

```json
{
  "ok": true,
  "rosConnected": true,
  "system": {
    "memUsedPercent": 45,
    "load1m": 1.2
  }
}
```

#### GET /api/snapshot

获取完整系统快照（含 maps、navPoints、virtualObstacles、runtime）。

### 7. 地图管理接口

| 方法 | 路径 | 说明 | 角色 |
|------|------|------|------|
| GET | `/api/maps` | 获取地图列表 | 所有 |
| POST | `/api/maps/save` | 保存当前地图 | 所有 |
| POST | `/api/maps/import` | 导入 PGM 地图文件 | 所有 |
| DELETE | `/api/maps/:id` | 删除地图 | admin |
| PUT | `/api/maps/:id/rename` | 重命名地图 | admin |
| PUT | `/api/maps/:id/pcd` | 更新地图的 PCD 关联 | 所有 |
| POST | `/api/maps/:id/switch` | 切换地图（激活） | 所有 |
| GET | `/api/maps/:id/export` | 导出地图 ZIP | 所有 |
| GET | `/api/maps/pcds` | 列出所有 PCD 文件 | 所有 |
| POST | `/api/map/publish` | 发布栅格到 /map 话题 | 所有 |

#### POST /api/maps/save

```json
// Request
{
  "name": "我的地图",
  "data": {
    "width": 1024, "height": 1024,
    "resolution": 0.05,
    "origin": {"x": -10, "y": -10},
    "data": [0, 100, -1, ...]
  },
  "pcd_path": "/path/to/pointcloud.pcd"  // 可选
}
// Response: 201 {"id": "uuid"}
```

#### POST /api/maps/:id/switch

切换激活地图，调用 `MAP_SWITCH_HOOK` 脚本。

### 9. 导航控制接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/nav/command` | 导航控制命令 |
| POST | `/api/nav/simple-goal` | 设置单点导航目标 |
| POST | `/api/nav/goal` | 设置 Action 导航目标 |
| POST | `/api/nav/tolerance` | 调节到达容差 |
| POST | `/api/nav/obstacle-dist` | 调节障碍物距离 |
| POST | `/api/nav/param/reconfigure` | 调节 TEB 参数（动态生效） |

#### POST /api/nav/command

```json
// Request
{"command": "start"}   // start | stop | pause | resume | nav-only

// start:     启动多点导航 (navMode=multi)
// nav-only:  仅启动导航栈，不发 Task.py (navMode=single)
// pause:     暂停 (kill Task.py)
// resume:    继续 (重启 Task.py)
// stop:      停止全部
```

#### POST /api/nav/simple-goal

```json
// Request
{
  "x": 1.5, "y": 2.0, "yaw": 1.57,
  "frame_id": "map"
}
```

#### POST /api/nav/param/reconfigure

```json
// Request
{"key": "xy_goal_tolerance", "value": 0.3}
```

#### POST /api/nav/param/rosparam

```json
// Request
{"key": "obstacle_range", "value": 5.0}
// 修改 costmap 参数，触发 move_base 防抖重启 (2s)
```

### 13. WebSocket 接口

**端点**：`ws://<机器人IP>:8080/ws`

**连接即推送**：完整 `snapshot` 事件。

**遥测推送**（200ms 间隔，差分）：

```json
{
  "event": "telemetry",
  "payload": {
    "tfPose": {"x": 1.0, "y": 2.0, "yaw": 1.57, "frame": "map"},
    "globalPlan": [{"x": 0, "y": 0}, {"x": 1, "y": 1}],
    "localPlan": [{"x": 0, "y": 0}, ...],
    "voxelGrid": [{"x": 0.5, "y": 0.3}, ...],
    "navStatus": "running",
    "hdlRunning": true,
    "lastVoxelAt": "2026-07-23T10:00:00.000Z",
    "lastTfAt": "2026-07-23T10:00:00.100Z",
    "ts": "2026-07-23T10:00:00.200Z"
  }
}
```

**事件广播**（状态变化时）：

| 事件 | 触发时机 |
|------|----------|
| `nav_status` | 导航状态变化 |
| `mapping_status` | 建图状态变化 |
| `lidar_status` | 雷达状态变化 |
| `motion_status` | 运控状态变化 |
| `nav_goal` | 设置导航目标 |
| `nav_points` | 导航点列表变化 |
| `maps` | 地图列表变化 |
| `virtual_obstacles` | 虚拟障碍物变化 |
| `mapping_complete` | 建图完成 |
| `topology_saved` | 拓扑点保存 |

### 14. 错误码

| 状态码 | 说明 |
|--------|------|
| 200 | 成功 |
| 201 | 创建成功 |
| 400 | 请求参数错误 |
| 401 | 未认证或 Token 过期 |
| 403 | 权限不足 |
| 404 | 资源不存在 |
| 409 | 资源冲突（如用户名重复） |
| 429 | 请求频率超限（导航目标） |
| 500 | 服务器内部错误 |
